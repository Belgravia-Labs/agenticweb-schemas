# Security Policy

If you discover a security vulnerability on `https://agenticweb.wiki`, the `/check/` conformance scanner, or the `/mcp` Streamable HTTP server:

- **Email:** `security@agenticweb.wiki`
- **Security Charter & RFC 9116 `security.txt`:** <https://agenticweb.wiki/security/> (`/.well-known/security.txt`)

Please do not disclose unpatched vulnerabilities in public GitHub issues.
